## What was searched

- The open web and arXiv, over the Erdős–Straus literature: the
  historical line (Erdős–Straus–Schinzel; Obláth; Mordell;
  Vaughan 1970; Terzi; Sierpiński–Schinzel), surveys and counting
  work (Bloom–Elsholtz; Elsholtz–Tao; Elsholtz–Planitzer),
  generalisation bounds (Pomerance–Weingartner), and the recent
  wave of exceptional-set exponent claims (Dahan; Trybushnyi;
  Kandukoori–Ramesh–Kumar), including their companion formalisation
  artefacts where public.
- The framework source for Component 2: SIEVE-beta(p, d) is a
  statement family inside Dahan's framework; the (151, 5) instance
  arises as the smallest d > 1 instance at p = 151 in that
  framework's own terms, and the search covered the framework
  texts and the work citing them that the open web and arXiv
  surface.
- Extremal-prime / hardness data for the margin statistic of
  Component 1, as surfaced by the same channels.

## Limits of the search — stated plainly

- **Vaughan 1970's paper body is paywalled and was never read in
  primary.** Its result (the exceptional-set exponent 2/3) is
  known to the search only through statements of it in other
  works. A component of this package appearing inside that paper
  would have been missed.
- **No MathSciNet access.** A result published only in a venue
  indexed there and nowhere on the open web or arXiv would have
  been missed. The same applies, with the same consequence, to
  zbMATH-only coverage.
- MathOverflow / Math StackExchange coverage is incomplete: no
  citable thread was retrieved, and those sites' internal search
  was not used. This is incomplete coverage, not a negative
  result.
- Some located items were retrievable only at abstract level, and
  some companion artefacts were known only through citations in
  other works; their full texts were not read.
- Non-English literature was reached only where the open web or
  arXiv surfaced it.

## Consequence for wording

Every description of this package, in this package, is written to
match this graded verdict: the components are presented as a
certified computational result at stated bounds (Component 1) and
as a decided instance of a named framework statement (Component 2),
with this file attached. Any stronger description, by anyone,
exceeds what the search supports.
